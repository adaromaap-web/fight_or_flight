# Fight or Flight

**Fight or Flight** — визуальная новелла, разработанная на **Ren'Py** с поддержкой мобильных устройств.

Проект сочетает классический формат визуальной новеллы с системой выборов, влияющих на дальнейшее развитие истории и отношения между персонажами.

## О проекте

Игрок управляет главной героиней и принимает решения, которые определяют её поведение и взаимодействие с другими персонажами.

В игре присутствуют:

* диалоговая система;
* выборы с несколькими вариантами действий;
* система отношений между персонажами;
* выборы, последствия которых могут проявляться позже;
* несколько персонажей с отдельными ветками взаимодействия;
* система сохранений;
* автоматическое сохранение прогресса;
* возможность продолжить игру с последнего сохранения;
* отдельные экраны для важных игровых событий и выборов;
* адаптированный вертикальный интерфейс для мобильных устройств.

## 📖 Первая глава

На текущем этапе полностью завершена **Глава 1**.

В ней реализованы:

* вступительная последовательность;
* знакомство с персонажами;
* первые сюжетные выборы;
* выбор напитка;
* выбор, связанный с курением;
* система изменения отношений между персонажами;
* последствия некоторых решений;
* финальный экран первой главы.

Глава 1 является законченной игровой частью и используется как основа для дальнейшего развития истории.

## Визуальная часть

Проект использует собственные графические материалы и специально созданный интерфейс.

Интерфейс адаптирован под вертикальное разрешение и ориентирован прежде всего на мобильное прохождение.

Для оформления используются:

* собственные изображения персонажей;
* фоновые изображения;
* отдельные изображения для сюжетных экранов;
* кастомные шрифты;
* собственные элементы интерфейса;
* затемнение и визуальные состояния интерактивных элементов.

## 💾 Система сохранений

В проекте реализована система автоматического сохранения.

Игра периодически создаёт автоматическое сохранение, а пункт **«Продолжить»** в главном меню позволяет загрузить последнее доступное автосохранение.

При отсутствии сохранений игрок получает соответствующее уведомление.

## 📱 Мобильная версия

Проект разрабатывается с учётом запуска на мобильных устройствах.

В интерфейсе предусмотрена отдельная адаптация для небольших экранов:

* увеличенные элементы управления;
* увеличенный размер текста;
* вертикальная компоновка;
* адаптированные кнопки и отступы.

Основная целевая платформа на текущем этапе — **Android**.

### Основные файлы

**`script.rpy`**
Содержит сценарий игры, персонажей, сюжетную логику, выборы и обработку последствий.

**`screens.rpy`**
Содержит пользовательский интерфейс игры: главное меню, экраны выбора, кнопки управления, уведомления и другие интерактивные элементы.

**`gui.rpy`**
Отвечает за глобальные настройки интерфейса, размеры элементов, шрифты, цвета и адаптацию GUI.

## Запуск проекта

Для запуска проекта требуется:

1. Установить **Ren'Py 8.5.2** или совместимую версию.
2. Добавить проект в Ren'Py Launcher.
3. Выбрать проект **Fight or Flight**.
4. Запустить игру через **Launch Project**.

## Сборка Android

Для создания Android-версии:

1. Открыть проект в Ren'Py Launcher.
2. Выбрать раздел **Android**.
3. При необходимости установить Android SDK и необходимые компоненты.
4. Выполнить сборку APK.

Готовая сборка используется для тестирования игры на Android-устройствах.
